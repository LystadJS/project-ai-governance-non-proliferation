# Reproducibility

## Environment

The coordinate-reproduction script uses base R only. The publication-style figure script uses:

- `tidyverse`
- `ggplot2`
- `ggforce`
- `ggrepel`
- `scales`

Use a current R 4.x release. Package versions should be recorded when the public repository is frozen for a tagged release.

## Execution order

From the repository root:

```bash
Rscript analysis/01_pcoa_process_terrain.R
Rscript analysis/02_strategic_terrain_figure.R
```

The first script writes the coordinate and diagnostic files under `pcoa_outputs/`. The second script consumes `pcoa_outputs/pcoa_coordinates.csv` when available and writes publication-style figures under `figures/`.

## Expected coordinate checks

The PCoA workflow contains numerical assertions that should pass before generated outputs are treated as reproduced:

```text
Lingoes constant:               0.0107432366
PCoA 1:                        39.804568%
PCoA 2:                        27.093710%
PCoA 1 + PCoA 2:               66.898278%
maximum coordinate error:       < 1e-5
```

The expected oriented coordinates are embedded in the script and are checked programmatically.

## Optional actor-position input

`analysis/02_strategic_terrain_figure.R` may optionally consume:

```text
data/actor_venue_involvement.csv
```

with columns:

```text
actor
venue
involvement_weight
evidence_breadth
```

That optional file is **not included** in the initial public release. When absent, the plotting workflow uses the explicitly coded fallback country positions. The absence of that file therefore does not prevent figure generation.

## Interpretation boundary

The coordinate workflow reproduces similarity among process-evidence profiles. It does not estimate political influence, alignment, causal effects, national preference, or institutional effectiveness.

The publication-style visualization also contains descriptive functional halos and contextual nodes that are not generated by the PCoA itself. Those elements are intentionally labeled as contextual/descriptive rather than inferential outputs.

## Non-public components

The broader private working project includes analytical materials beyond this release. Their absence from this repository is intentional and should not be interpreted as missing dependencies for the public PCoA baseline.
