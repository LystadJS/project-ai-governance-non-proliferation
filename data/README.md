# Data Boundary

The initial public release does not publish the private working corpus used elsewhere in the broader AI-governance research program.

## Included analytical input

The core PCoA script embeds the releasable **7 × 19 process-evidence matrix** directly in code. That matrix is sufficient to reproduce the published process-terrain coordinates and diagnostics.

## Not included

The public repository does not include:

- source-body archives;
- private evidence packets;
- proposal-by-provision working panels;
- private actor-position files;
- internal coding notes;
- negotiation working files;
- private intermediate model objects; or
- decision-support products.

## Optional file

The plotting workflow can optionally read:

```text
actor_venue_involvement.csv
```

with columns `actor`, `venue`, `involvement_weight`, and `evidence_breadth`.

This file is intentionally absent from the initial public release. Without it, the plotting workflow uses the fallback positions coded in the script.

Any later public dataset added to this directory should include source provenance, retrieval dates, redistribution terms, variable definitions, and a clear statement distinguishing observed data from constructed analytical features.
