# Rights and Reuse

This public release is provided for research transparency, reproducibility, and citation.

No blanket license is asserted over third-party source materials or over materials that are not actually included in the repository. Public visibility does not transfer rights in underlying institutional documents, source archives, trademarks, or externally produced materials.

Repository code and written documentation may later receive an explicit software/content license after a deliberate licensing review. Until then, users should cite the repository version used and contact the author before redistributing substantial portions as a derivative package or republishing figures outside normal scholarly quotation and citation practice.

The private working repository and its non-public materials are outside the scope of this public release.
